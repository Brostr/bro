## 📞 Como Usar

Quando encontrar um bug ou problema:
1. Verifique `BUGS_RESOLVIDOS.md` para ver se já foi resolvido antes
2. Consulte `FLUXOS.md` para entender como o sistema deveria funcionar
3. Use `ARQUITETURA.md` para entender onde cada componente está
4. **Antes de mexer em comprovante/status/taxas/Tor, leia
   `LICOES_APRENDIDAS_NOV2026.md`** — ele documenta os erros que custaram
   3 iterações para resolver
